# Ametista packs

Public pack catalog for the [Ametista launcher](https://github.com/LuizFps120hz/ametista-launcher).

- `packs.json` lists the public packs shown in the launcher.
- `packs/<id>/` holds each pack in [packwiz](https://packwiz.infra.link/) format. Mods are
  referenced by their original download URL and hash (e.g. Modrinth); nothing here is a mod
  marketplace.

This repository is updated by the launcher's admin area. Please do not edit it by hand.
